# prospectus-analysis

深度分析招股说明书的 Claude Code skill。

基于《招股说明书原来可以这样玩》（何炳喻，2014）的 LROE 心法，
结合专业投资分析框架，支持 A股/港股/美股 IPO 分析。

## 功能
- LROE 四维心法 + 五视角同读法
- 七步成诗法读企业（找"不变量"）
- 产业四规律定位行业周期
- 逐章解读招股书信号
- 财务质量与红旗识别
- IPO 估值与打新决策
- 生物医药专项框架（管线/专利/监管/rNPV）
- 16 个配套 skill 编排

## 安装
```
skill install https://github.com/kiklata/prospectus-analysis-skill
```

## 使用
发送招股书内容或说"分析 XX 公司招股书"即可触发。
